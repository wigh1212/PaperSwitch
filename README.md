# Paper Switch — PDF · SVG · WebP 크롬 확장 프로그램

## 현재 버전: 0.5.1

- 기본 화면은 영어이며 English / 한국어 / 日本語 / 简体中文을 선택할 수 있습니다. 선택한 언어를 기억하고 파일 내용과 파일명은 번역하지 않습니다. OCR 인식은 기존 한국어·영어입니다.
- next.svg / prev.svg의 직접 지정 스타일이 검정으로 변하던 문제를 수정했습니다. CSS 클래스·변수·상속·인라인 색상을 변환 전에 확정하고 벡터를 유지합니다.
- 화면, 배치 처리, 변환 서비스, 다운로드, 접근 정책을 분리했습니다. 로그인·구독 결제는 아직 구현하지 않았습니다.
- 유지보수 구조와 향후 서버/구독 연결 지점은 [구조 설명](docs/ARCHITECTURE.md), 라이브러리 관리는 [의존성 안내](config/README.md)를 참고하세요.

### 0.2.0 추가 기능

- PDF → SVG, SVG → PDF, PDF → WebP, WebP → PDF를 각각 버튼으로 선택합니다.
- 한 번에 최대 20개 파일: 파일당 50 MB, 입력 합계 100 MB, 결과 합계 150 MB.
- 파일별 진행 상태와 오류 안내, 개별 다운로드와 전체 ZIP 다운로드를 지원합니다. 같은 이름의 입력은 번호를 붙여 구분합니다.
- 일부 파일이 실패해도 나머지는 계속 변환합니다. 취소하면 해당 실행 결과를 버리고 다시 실행할 수 있습니다.
- PDF → WebP는 PDF당 최대 100페이지, 72/144/216 dpi 크기 선택, 품질 92%, 흰 배경입니다. WebP는 벡터나 선택 가능한 글자를 유지하지 않습니다.
- WebP → PDF는 이미지당 별도의 1페이지 PDF를 만듭니다(96픽셀 = 1인치). 투명 배경은 흰색, 애니메이션은 첫 프레임으로 저장합니다. 이미지당 최대 2,400만 픽셀입니다.

### 0.1.1 수정 사항

- Illustrator SVG의 클래스 스타일이 보안 정책에 막혀 검정으로 변환되던 문제를 수정했습니다. 빌드 시 svg2pdf의 스타일 파서를 DOM 삽입 대신 CSSStyleSheet 데이터 파싱으로 교체하며 기존 보안 정책을 유지합니다.
- NanumMyeongjoBold 폰트를 로컬에 포함해 해당 폰트를 사용하는 한글 텍스트를 PDF에 임베딩합니다. 다른 임의의 폰트를 모두 지원하는 것은 아닙니다. 폰트 출처: https://github.com/google/fonts/tree/main/ofl/nanummyeongjo , 라이선스: `extension/fonts/OFL.txt`.
- 크롬 보안 정책을 적용한 테스트에서 클래스 기반 색상을 픽셀로 검증합니다. SVG_FIXTURE 환경 변수로 실제 SVG를 지정하면 원본과 PDF의 렌더링 비교도 실행합니다.
- 업데이트 후 `chrome://extensions`에서 Paper Switch의 새로고침 버튼을 누르고 열려 있는 변환 탭도 새로고침하세요.

첫 버전입니다. 파일은 서버로 업로드되지 않으며, 포함된 변환 엔진으로 브라우저 안에서 처리합니다.

## 바로 설치하기

1. 크롬 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 프로젝트 안의 **extension** 폴더를 선택합니다. `chrom-dev` 전체가 아니라 `manifest.json`이 들어 있는 폴더입니다.
5. 크롬 오른쪽 위 퍼즐 아이콘에서 **Paper Switch**를 누릅니다. 변환 화면이 새 탭으로 열립니다.
6. 변환 방향을 고르고 파일을 선택한 뒤 **변환 → 파일 다운로드**를 누릅니다.

설치에 개발 도구나 명령어 입력이 필요하지 않습니다. `extension/vendor`에 엔진이 포함돼 있습니다. 수정 후에는 확장 프로그램 관리 화면에서 새로고침하고 변환 탭도 새로고침하세요.

## 지원 기능

- PDF → SVG: 전체 또는 지정한 페이지. 예: `1, 3-5`.
- 여러 페이지는 페이지별 SVG를 ZIP 파일 하나로 제공합니다.
- SVG → PDF: 원본 크기의 한 페이지 PDF.
- 파일 끌어놓기, 진행 상태, 취소, 오류 안내.
- 한 번에 20개, 파일당 50 MB, 입력 합계 100 MB, PDF당 최대 100페이지, 결과 합계 150 MB 제한.
- 서버·계정·분석 수집·웹사이트 접근 권한 없음.

## 변환 범위

스캔 PDF는 사진이므로 SVG로 바꿔도 이미지로 남습니다. 벡터 도형은 가능한 한 유지되며, PDF 글자는 SVG 경로가 될 수 있습니다. OCR이나 자동 윤곽선 추출은 포함하지 않습니다. 복잡한 SVG CSS·필터·폰트는 다르게 표현될 수 있습니다. 외부 파일 참조, 스크립트, HTML을 포함한 SVG와 암호를 요구하는 PDF는 지원하지 않습니다. 링크·양식 등 문서의 상호작용 기능을 보존하는 도구가 아닙니다. 변환 후 모양을 확인해 주세요.

## 개발

Node.js 22 이상과 pnpm을 권장합니다.

```text
pnpm install --frozen-lockfile
pnpm build
pnpm test
```

`extension/app.js`는 화면 동작, `worker.js`는 별도 작업 스레드 변환, `core.js`는 페이지 선택과 변환, `style.css`는 디자인입니다. 별도의 서버나 빌드 서비스는 필요하지 않습니다.

## 확인한 내용

자동 테스트로 페이지 선택, 잘못된 입력, PDF 변환의 벡터 유지·크기·렌더링 픽셀, ZIP 내용을 검사합니다. `tests/browser.mjs`는 크롬에서 두 방향의 다운로드와 오류 안내를 검사하며, 실행하려면 Playwright 설치 위치를 PLAYWRIGHT_MODULE 환경 변수로 지정합니다. 복잡한 실제 문서 전체의 호환성을 보증하지는 않습니다.


## 0.3.0 — PNG · TXT · TIFF
- 세 형식 모두 PDF와 양방향 변환, 기존과 동일한 좌우 버튼 및 여러 파일 다운로드를 지원합니다.
- PNG·TIFF 출력은 페이지별 이미지, TIFF는 무압축 RGB입니다. TIFF 입력은 모든 페이지를 PDF 한 개로 모읍니다.
- PDF → TXT는 선택 페이지를 UTF-8 파일 하나로 모읍니다. 글자가 없는 스캔에는 OCR이 필요하다는 오류를 표시합니다.
- TXT → PDF는 UTF-8, A4, 한글 폰트 포함, 자동 줄바꿈·페이지 나눔을 지원합니다. 최대 20만 글자·100페이지입니다. 표·이미지·원본 서식은 복원하지 않습니다.


## 0.3.1 — 오프라인 OCR
- PDF → TXT에서 글자가 없는 페이지는 Tesseract.js 6.0.1로 한글·영어를 인식합니다. 모든 페이지 OCR 옵션도 제공합니다.
- Tesseract 엔진·언어 데이터는 확장 프로그램에 포함돼 파일 업로드나 실행 중 다운로드가 없습니다. 언어 데이터 출처: https://github.com/tesseract-ocr/tessdata_fast (Apache-2.0). 라이선스는 extension/vendor/ocr에 포함합니다.
- 작은 글자, 손글씨, 다단 문서, 기울어진 사진은 오인식할 수 있습니다. 자동 모드는 텍스트가 조금이라도 있는 페이지의 나머지 이미지는 인식하지 않으므로 필요하면 모든 페이지 OCR을 선택하세요.
- 이미지 기반 한글·영어 PDF를 만들어 텍스트 인식 결과를 검사했습니다.


## 0.4.0 — 기준 탭 및 SVG 이미지 변환
- PDF 기준 / SVG 기준 탭으로 분리했습니다. PDF 탭의 기존 양방향 기능을 유지하고 SVG 탭에도 SVG → PDF를 제공합니다.
- SVG → PNG/JPG/WebP/TIFF: 원본 픽셀 기준 1/2/3배, 흰 배경, 기존 여러 파일 처리와 ZIP 지원. 이미지 변환은 벡터 편집 정보를 보존하지 않으며 설치되지 않은 글꼴은 대체될 수 있습니다.
- 변환 목록은 extension/conversions.js, SVG 이미지 변환은 extension/svg-image.js에 분리했습니다.
- 라이브러리 직접 버전은 package.json 한곳에 고정하고 하위 버전은 pnpm-lock.yaml로 관리합니다. 자세한 업데이트 방법은 config/README.md를 확인하세요.
- build는 패키지 버전과 외부 폰트·OCR 데이터의 검증값을 확인합니다. SVG 탭 5개 형식의 색상·크기·여러 파일 결과와 기존 PDF/OCR 흐름을 브라우저에서 검사했습니다.


## 0.4.1 — SVG 탭 양방향
- 각 줄을 SVG → 형식 / 형식 → SVG로 배치합니다. PDF·PNG·JPG·WebP·TIFF의 역방향 변환과 일괄 다운로드를 지원합니다.
- 이미지 → SVG는 이미지 데이터를 포함하는 방식이며 자동 벡터 추적이 아닙니다. WebP 애니메이션은 첫 프레임만 저장합니다. TIFF는 페이지별 SVG로 저장합니다.
