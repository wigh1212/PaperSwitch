# Paper Switch 페이지 구조 개선

2026년 10월 14일. 로컬 수정 및 검증 기록이며, 운영 배포나 AdSense 재검토 요청 완료 기록이 아닙니다.

## 변경 결과

- 변환 페이지를 생성할 때 확장 프로그램의 전체 메뉴, 다른 변환 패널, 편의기능 소개, 공통 PDF·SVG·OCR·TIFF 안내를 제거합니다. 화면에서 숨기던 내용을 공개 HTML에서도 제거했습니다.
- 해당 변환에서 실제 사용하는 옵션만 제공합니다. PDF 입력의 페이지 범위, PDF 이미지 출력의 해상도, PDF 텍스트 추출의 OCR, PDF 출력의 병합 선택을 각각 구분합니다.
- QR 읽기에는 이미지 선택과 추출 결과만, 일반 QR 만들기에는 텍스트 입력과 디자인만, 와이파이 QR에는 네트워크 입력과 디자인만 들어갑니다.
- HEIC 변환에서 PDF 페이지 선택을, 이미지 크기 변경에서 배경 제거를, PDF 페이지 편집에서 해당 작업과 무관한 설정을 제거했습니다.
- 각 도구 상단에서 사용법과 결과·제약사항으로 바로 이동합니다. 기존 실제 변환 예제와 원본·결과 다운로드를 유지했습니다.
- QR 읽기 실패 대처, QR 목적지 변경, 와이파이 연결 확인, 픽셀 크기와 KB 용량 구분에 대한 네 언어 안내를 추가했습니다.
- 이미지 변환 주의사항을 입력·출력에 맞게 정리했습니다. PNG/JPG 변환에서 무관한 WEBP 애니메이션이나 TIFF 페이지 안내가 나오지 않습니다. 별도 옵션이 없는 변환은 사용법에서 존재하지 않는 옵션을 요구하지 않습니다.
- 홈페이지의 실제 결과 예제와 도구 선택 안내는 펼치기 없이 보입니다.

## 구현

`scripts/focus-tool-page.mjs`가 빌드 단계에서 공개 페이지에 필요한 요소만 남깁니다. 기능 엔진은 없는 입력창에 의존하지 않도록 수정했으며, 기존 확장 프로그램 HTML은 유지합니다. 페이지 수·공개 주소·사이트맵·canonical·hreflang·광고 연결 코드는 그대로 유지합니다.

`web/task-guides.mjs`, `web/conversion-notes.mjs`, `web/experience-copy.mjs`의 번역을 정적 생성과 브라우저 언어 변경에 함께 사용합니다. 관련 도구 링크, 서비스 소개, 문의 및 개인정보·이용 안내도 유지합니다.

## 검증

- 생성 결과: 47개 도구, 네 언어를 포함한 208개 페이지.
- 단위·구조·라우팅 검사: 30개 통과. 도구 페이지 188개의 실제 HTML에서 무관한 입력과 패널이 제거됐는지 포함합니다.
- 전체 208개 페이지: 제목·설명, canonical·hreflang, 사이트맵, 내부 링크, 정적 자산, 광고 연결 코드 및 404 검사 통과.
- 직접 관리하는 JavaScript 문법 검사 통과.
- 실제 파일을 이용한 변환·PDF 병합·QR 생성 및 읽기·이미지 크기 변경 검사, PDF 페이지 편집·와이파이 QR·HEIC 결과 검사.
- 네 언어 도구 페이지 188개의 실행, 320픽셀 모바일 폭, 안내 링크, JavaScript 없는 사용법과 홈페이지 예제 표시 검사.
- 공유 코드의 확장 프로그램 검사: PDF/SVG 및 OCR, 언어 유지, QR 왕복 인식·색상·로고, 이미지 크기 변경·배경 제거.

화면 확인용 이미지는 `test-results/focused-*.png`에 저장합니다. 로컬 미리보기 실행 후 홈페이지, PNG JPG 변환, QR 읽기에서 직접 확인할 수 있습니다.

## 운영 반영 후

배포 후 실제 공개 주소의 기능·문구와 주요 예제 다운로드를 다시 확인하고, Search Console에서 대표 페이지의 크롤링 결과를 확인합니다. AdSense의 검토 요청은 운영 사이트에 수정본이 반영된 뒤 진행합니다. 이번 개선은 반복 콘텐츠와 이용 흐름을 개선한 것으로, Google의 내부 심사 원인을 확정하거나 승인을 보장하지 않습니다.
