# 라이선스 정리 상태 — 2026-09-22

사용자가 현재 기능 유지 및 AGPL 조건에 따른 소스 공개를 선택했다. 프로젝트 LICENSE와 package.json을 AGPL-3.0-or-later로 지정했다. 제3자 코드에는 원래 라이선스를 유지하며 사용자가 업로드하는 문서에는 이 라이선스를 부여하지 않는다.

## 구현 및 검증
- 하단 오픈소스 고지에서 75개 설치 의존성·번들·폰트·데이터의 라이선스 전문과 소스 다운로드를 제공한다. 개발·선택 의존성도 목록에 포함한다.
- 같은 빌드에 사용한 프로젝트 파일을 source zip으로 생성한다. 소스, 테스트, 빌드 스크립트, 버전 고정 파일, 필요한 폰트/OCR 데이터, LICENSE와 빌드 설명이 포함된다.
- 공개 묶음은 명시한 디렉터리와 파일만 수집한다. .git, .env, 자격증명 경로, 작업 로그, 캐시, test-results는 제외한다.
- 공식 MuPDF 1.28.0 전체 source 배포본과 heic-to 1.5.2, libheif 1.22.2, libde265 1.0.16 source를 직접 제공한다. 원본 URL과 SHA-256을 고정하고 빌드 시 검증한다.
- 큰 소스 파일은 20 MiB 조각으로 제공한다. 순서대로 바이너리 결합하는 방법과 원본 전체 파일 링크를 함께 제공한다.
- svg2pdf.js의 스타일 파싱 수정 내역을 고지했다. LGPL 라이브러리 교체 경로와 빌드 지침을 SOURCE-BUILD.md에 설명했다.
- 게시되는 소스 파일·조각 해시, 로컬 코드와 일치 여부, 필수 빌드 입력, 광고 없는 고지 페이지를 자동 검사한다.

## 남은 기술 확인 범위
- MuPDF npm 패키지의 reported gitHead와 공개 릴리스 tag가 다르다. 공식 동일 버전 원본을 제공하지만 npm 포장 커밋과 native 빌드의 정확한 대응은 upstream 확인 대상이다.
- MuPDF WASM 및 HEIC 내장 디코더를 이 환경에서 재컴파일해 bit-for-bit 비교하지 않았다. 출처와 재현 절차를 제공한 것을 완전한 바이너리 재현 검증으로 표현하지 않는다.
- native 라이브러리 하위 구성요소는 원본 소스 배포본의 각 고지를 함께 따른다. 소스 제공·표시 의무 전체가 충족됐다는 법률 인증을 의미하지 않는다.
- 향후 의존성 변경 시 source-archives.json과 고지를 갱신하고 이전 배포 버전의 소스 접근을 보존해야 한다.

## 운영 반영
아직 배포하거나 GitHub에 push하지 않았다. 현재 제공물은 로컬 dist에 준비돼 있으며 배포 후 하단 링크와 큰 소스 파일 다운로드를 실제 도메인에서 확인해야 한다. 공개 방침을 선택했다고 저장소 공개 설정을 임의 변경하지 않는다.
