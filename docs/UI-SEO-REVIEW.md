# UI 및 SEO 개선 기록

실제 운영 주소: https://paperswitch.saerokbit.com/

## 확인한 내용
- 홈페이지, 한국어 홈, 한국어 JPG→PDF 페이지는 HTTP 200이며 X-Robots-Tag noindex가 없었습니다.
- 확인한 페이지의 canonical은 현재 운영 도메인과 언어별 주소를 가리킵니다.
- robots.txt는 크롤링을 허용하고 현재 도메인 sitemap.xml을 안내합니다. 사이트맵도 HTTP 200입니다.
- 이 결과는 Google 색인 완료나 순위 확인을 의미하지 않습니다. Search Console 실적과 색인 보고서에는 접근하지 않았습니다.

## 변경
- 홈에 작업 목적별 바로가기 6개를 배치하고 파일 형식별 전체 도구는 펼쳐 보기로 정리했습니다.
- 도구 선택을 돕는 실제 사용 예시와 관련 도구 링크를 제공합니다.
- 중복 소개 문단을 제거하고 PDF 편집·HEIC·와이파이 QR의 사용 순서를 구체화했습니다.
- PDF 편집의 원본 보존·암호 제한, HEIC의 Live Photo 제한 FAQ를 4개 언어로 추가했습니다.
- 역변환과 다음 작업을 우선하는 내부 링크를 적용했습니다.
- 새 도구나 검색어만 다른 중복 페이지는 추가하지 않았습니다.

## 검증
- 192개 정적 HTML의 언어별 고유 제목, 설명, canonical, hreflang, 내부 링크 및 사이트맵 수 확인.
- 모바일 320/390px, 키보드 탭 탐색, 언어 변경 후 링크, JavaScript 없는 홈 확인.
- 실적 평가는 배포일을 기준으로 Search Console의 페이지·검색어·국가별 노출, 클릭, CTR을 비교해야 합니다. 낮은 CTR은 순위와 함께 해석합니다.
- 아직 배포하지 않았습니다.
